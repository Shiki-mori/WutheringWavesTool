# Node 历史记录补录

补录使用 `analyzer_records`，一行仍代表一抽。历史五星之间的未知物品使用占位行，名称、ID、星级、UP、时间和同秒序号均为 `NULL`。五星保留文档名称和 UP 信息，物品 ID 只从同池现有五星记录可靠匹配，否则为 `NULL`。

历史前缀使用连续负数 `draw_order`，已有官方记录的字段及正数序号保留。文档末尾与官方记录开头的重叠五星只保留一次，并补足首个官方五星之前已过期的抽数。抽数按实际行数计算，不使用业务序号差值。

文档格式沿用 `expiredGachaRecords/records.md`：每池最旧在前，角色每行是“名称 抽数 UP标记”，其中 **0 为 UP、1 为非 UP**；武器每行是“名称 抽数”。支持角色活动、武器活动、常驻武器三个标题。武器五星沿用现有数据库的 `is_up=1` 编码，本次不调整常驻武器 UP 统计口径。

## 安装与预演

从仓库根目录执行：

```bash
(cd backend_node && npm ci)
(cd backend_node && npm test)
(cd backend_node && npm run records:import)
```

默认读取仓库内的历史文档并使用 `utils/db.js` 配置。默认只读预演：不创建备份、不迁移表、不写记录。输出新增行数、重叠数量、边界补抽数及各池拼接后的统计，不打印玩家 UID 或逐抽数据。

```bash
(cd backend_node && npm run records:import -- --file /absolute/path/records.md)
```

数据库只有一个用户时自动选中；有多个用户时必须显式使用 `--uid`，只修改该用户的数据。查询接口的现有跨用户统计行为未改变。重叠不唯一、无法匹配、已有其他历史批次或不完整批次时会停止，不猜测插入位置。

## 正式入库

暂停官方链接抓取入库，核对预演结果后执行：

```bash
(cd backend_node && npm run records:import -- --apply)
```

流程为：获取补录会话锁 → 读取一致性快照 → 备份 → 必要时迁移来源字段 → 数据事务内锁定目标用户记录范围 → 再核对备份基线 → 插入 → 核对原始字段、完整出金序列及所有统计 → 提交。任一步数据核验失败会回滚数据事务。默认每池最多补录 100,000 行，超过该规模需人工核对。

结构迁移位于 `database/001_historical_records.sql`，新增：

- `data_source`：`official`、`manual`（手动五星）、`placeholder`（未知抽卡）。既有记录及后续官方导入默认为 `official`。
- `import_batch_id`：补录批次。批次与用户、卡池、业务序号组成补录唯一索引，原有官方记录唯一索引保留。

首次 `--apply` 自动执行迁移。**DDL 在数据事务之外执行**；后续数据失败不会撤销已经完成的结构迁移。不完整或不兼容的迁移会拒绝执行，脚本不会删除或覆盖既有列。

备份默认写入已忽略的 `backend_node/backups/`，包含完整原表结构和逐抽数据，文件权限为 `0600`，不会写入文档、测试或版本控制。时间以数据库原始 `YYYY-MM-DD HH:mm:ss` 字符串保存。可通过 `--backup-dir` 指定其他本机目录。备份失败时不会执行结构或数据修改。

批次 ID 根据解析后的文档生成，空白或换行变化不产生新批次；也可显式使用 `--batch-id`。重复执行完整批次不会增加记录或创建额外备份。新增官方记录后仍能识别原批次，保留最新尾部。重复执行检测会核对来源、顺序、名称、星级、UP、时间等字段，发现部分写入或异常字段会停止。

## 撤销批次

先用预演输出中的批次 ID 检查将删除的记录：

```bash
(cd backend_node && npm run records:import -- --rollback --batch-id expired-example)
```

加入 `--apply` 才会备份并在事务内删除该用户、该批次的负数手动记录。官方记录和补录之后的官方增量均保留；来源字段及索引保留。不存在的批次不执行删除。

```bash
(cd backend_node && npm run records:import -- --rollback --batch-id expired-example --apply)
```

提交阶段若连接异常，客户端可能无法确认服务器是否已提交；先对同一文档和批次运行只读预演核对，不直接重做另一批次。
